Library Management Made Simple

Cloud Library Management System is a web application designed to help libraries organize books,members, borrowing and returns efficiently.

This project demonstrates web development and will later integrate cloud technologies including Amazon EC2,RDS,S3,CloudWatch and AWS Secrets Manager.

Library Features

Books

Browse,search,add,edit and manage books in the library.

Members

Register and manage library members and their account information.

Borrow&Return

Keep track of borrowed books,due dates and returned books.

Dashboard

View important library statistics and current activity.
